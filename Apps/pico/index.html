关于 Pico

Pico 图片查看器 v1.7.1

一款纯前端、零依赖的本地图片查看器：网格浏览、丝滑缩放、幻灯片与 EXIF 信息，所有文件均不上传。

GitHub 项目主页：github.com/moli-xia/netupdown

设计灵感与致谢： PhotoSwipe · Viewer.js · ImageGlass · nomacs · qView
