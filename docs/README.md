## 术语表

全部文档统一使用以下术语，代码命名与之对应：

| 术语 | 代码/英文 | 说明 |
|---|---|---|
| 应用 | App | 站点发布的一款自研软件产品；旧收录类型仅作数据兼容保留 |
| 版本 | Release | 应用的一次发布，含版本号、渠道、更新日志 |
| 文件 | Asset | 版本下的一个具体安装包/压缩包，按操作系统与架构区分 |
| 下载源 | DownloadSource | 文件的一个获取渠道；「托管源」存于我方存储，「外链源」指向网盘等第三方 URL |
| 存储 | Storage | 一个已配置的存储后端实例（如"我的 R2 桶"） |
| 存储驱动 | Driver | 存储类型的实现：`local` / `s3` / `webdav` |
| 渠道 | Channel | 发布渠道：`stable` / `beta` / `alpha` |
| 主题 | Theme | 前台模板 + 静态资源的可插拔包 |
| 提取码 | ExtractCode | 网盘外链附带的访问密码 |

## 阅读约定

- 优先级标注：**P0** = MVP 必须；**P1** = v1.0 发布前完成；**P2** = 规划中，按需排期。
- 文档中出现的 `F-xxx` 为功能编号，定义见 [01-overview.md](01-overview.md)。
- 代码示例中的模块路径 `github.com/yourname/netupdown` 需替换为实际仓库路径。
- 所有时间存储一律 UTC，展示时按站点时区（默认 `Asia/Shanghai`）转换。
